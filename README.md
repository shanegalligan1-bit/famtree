# famtree

A living, record-based family tree — https://famtree.com

- `index.html` — the world layer: map of all families, cross-family relationship finder, GEDCOM overlap check.
- `galligan/index.html` — the Galligan · McCormack · Shine · Verling family tree (self-contained).
- `data/` — each family's shared data (deceased people, places, links) read by the world layer.
- Every person is marked **from a record**, **family account / best guess**, or **living**; living people are shown only as the family has given them, never researched.
- GEDCOM import and export live on the *Everyone* tab.

Built with Claude. Research log and sources are cited inside the page.
